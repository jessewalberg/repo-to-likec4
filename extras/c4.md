Handle the `/c4` command. Argument: `$ARGUMENTS`

- If the argument is **`update`** or **`upgrade`**: run
  `npx skills update repo-to-likec4` to pull the latest version of this skill
  repository into the agent, then report what changed if the command shows it.

- Otherwise, treat an empty argument, **`generate`**, or **`refresh`** as the
  current repository; treat any other argument as a repo path. Follow the
  **`cartograph`** skill end-to-end:
  1. Ensure engine dependencies with `npm install --prefix "$SKILL/assets/engine"`.
  2. Run `generate.ts` into `.cartograph/`.
  3. Run `bundle.ts` into `cartograph-site/index.html`.
  4. Verify `generate` prints `validate: OK`.
  5. If publishing is requested, copy `cartograph-pages.yml`, commit the generated
     site/workflow, and remind the user to set GitHub Pages source to
     **GitHub Actions** once.

Cartograph replaces old LikeC4 artifacts by default. Pass `--keep-c4` only if the
user explicitly asks to preserve legacy LikeC4 files.
