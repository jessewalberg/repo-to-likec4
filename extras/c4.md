description: LikeC4 architecture diagrams — generate/refresh them, or update the skill itself
argument-hint: "[update | generate | <repo path>]"
allowed-tools: Bash(npx skills:*), Bash(npx likec4:*), Bash(git:*)
---

Handle the `/c4` command. Argument: `$ARGUMENTS`

- If the argument is **`update`** (or `upgrade`): run
  `npx skills update repo-to-likec4` to pull the latest version of the skill into
  this agent, then report what changed (and the new version if shown). To refresh
  every installed skill instead, run `npx skills update`.

- Otherwise (empty, **`generate`**, **`refresh`**, or a path): follow the
  **`repo-to-likec4`** skill end-to-end for this repository (or the path given in
  the argument). Produce the **full view set** — System Context + Container map +
  a Component view for each significant service + 3–5 leaf-level flow views (which
  also render as sequence diagrams) + any applicable Data / External / Deployment /
  tag-overlay views — then `likec4 validate`, set up Pages for the repo's host
  (GitHub Actions workflow, or a GitLab `.gitlab-ci.yml` `pages` job — detect from
  the remote), and add the deployed-site link to the README. **Do not stop at
  flow diagrams.**
