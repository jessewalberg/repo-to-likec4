# cli.mjs

Root component that imports five factory subsystem modules (`envelope.mjs`, `diagrams.mjs`, `metrics.mjs`, `policy.mjs`, `schema.mjs`), providing the main entry point for the factory tool. As it has no importers, it serves as the primary user-facing interface for orchestrating these components.
